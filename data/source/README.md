# Teaching Source Data

Small, fictional, non-sensitive source files may be committed here so exercises are reproducible.

Guidelines:

- Keep files small enough to review in Git.
- Include deliberate quality problems only when documented by an exercise.
- Never add real customer, employee, or company data.
- Generated raw and curated outputs belong in ignored directories.

The first `customers.csv` file is intentionally not included. Creating and reviewing its schema is part of DE-001.
